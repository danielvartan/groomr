# Changelog

## groomr 0.1.0.9000 (Development Version)

- Added `get_file_sizes()` function to get the length files.
- Added
  [`replace_caps()`](https://danielvartan.github.io/groomr/reference/replace_caps.md)
  function to replace caps in an atomic vector.
- Added
  [`parse_html_table()`](https://danielvartan.github.io/groomr/reference/parse_html_table.md)
  function to parse HTML tables from a `character` vector.
